# A relayed answer settles nothing alone

> Layer: Requirements
> Context ticket: #174

An answer from someone outside the session reaches the grill only through the developer's tick or note. It closes its question for others, but every point it touches returns as a card the developer confirms. A tick never settles a point the way a mark on the developer's own card does.

## Considered Options

- Let a tick settle the point at once, as a mark does today. Rejected in card i-tick (devil's-advocate finding), because a relayed answer would then settle a point with no one reading it.

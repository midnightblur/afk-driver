# Each section keeps its own changes, always open

> Layer: Requirements
> Context ticket: #174

Each section and card shows its current text and its own change list, one line per round with its cause: a note, an answer, an answer from someone else, or an agent finding. The banner also lists the round's changes. There is no list of every change of every round, and change lists never fold, although pages grow: the developer wants the trajectory in view.

## Considered Options

- One change list for all rounds, never folded. Rejected by the developer's notes on card i-trail, in favour of changes shown where they happened.
- Old text struck beside the new text. Rejected by the developer's notes on card i-trail, because sections must always show the current information.

# Questions for others are a section of the grill page

> Layer: Requirements
> Context ticket: #174

Questions for people outside the session live in one section of the grill page, written so those people can read it, with links to the sections that help the discussion. There is no separate page, no outsider view and no button that hides the rest of the page: in a meeting the other sections are part of the discussion, and one page needs one wait. The developer: "just a section in the same page".

## Considered Options

- A separate page with its own link. Rejected by the developer in card i-outsider, because one section on the same page keeps one wait and one place.
- A button that hides the rest of the page while sharing. Rejected by the developer in card i-share, because seeing other sections is part of the discussion.

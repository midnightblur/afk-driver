R-2 Topology inherited: no new process, port or service Decided open i-l1

The scripts, the page document in the spec folder, the pinned lavish host and the browser stay as they are.

Decision

The topology is inherited: local Python scripts, the page document in the spec folder, the pinned lavish host and the browser; nothing new runs.

Why this one

The runner-up, a small local server that holds the living sections between rounds, loses because the engine already rebuilds the whole page from one file on each render.

Other options considered (rejected)

  • A local server that holds the sections: a new process to start, watch and stop
  • Inherited topology: nothing new to run

Evidencerepo

afkv2/engine/engine.py:458 rebuilds the page from the document on each render; afkv2/engine/launcher.py:32 pins the host at 0.1.80

To undo

Nothing to revert: the topology does not change.

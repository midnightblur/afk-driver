# Bootstrap before the first feature

> Status: Accepted
> Audited: 2026-10-19
> Layer: Requirements
> Context ticket: P2P-2067

A repository without glossary ownership uses a separate prerequisite merge request. The first feature requirements phase cannot close until routes, the owning glossary, and owner declarations reach the target branch.

## Considered Options

- Add bootstrap artifacts to the first feature merge request.
- Establish the ownership baseline in a separate merge request.

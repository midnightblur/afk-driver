# Consult relevant definitions

> Status: Accepted
> Audited: 2026-10-19
> Layer: Requirements
> Context ticket: P2P-2067

AFK selects definitions from changed-path routes, declared domain areas, exact terms, and bounded semantic fallback. It does not load an entire glossary unless every term is relevant.

## Considered Options

- Load every term from each affected service glossary.
- Load the smallest complete set supported by deterministic routes and bounded discovery.

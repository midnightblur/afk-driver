Contract checks: 22, one per contract row and per module with no row; each protected surface has its refused-agent test. Gaps for the plan: the final gate expects a running app (a plugin issue to draft, with your approval); CLAUDE_CONFIG_DIR and the secret step; CI does not run the two worktree smoke scripts; how setup detects the Codex app; the bare secret-step exit status.

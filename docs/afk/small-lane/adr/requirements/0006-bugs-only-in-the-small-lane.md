# The small lane takes bugs only

> Layer: Requirements
> Context ticket: small-lane

A bug of any size can enter the small lane. An enhancement never does: an enhancement is never small, and it always needs a proper grill. `/afk:to-ticket` can still file an ad-hoc enhancement ticket, and a grill picks it up. A bug that a grill finds too large goes into the full chain until a medium lane exists (#108).

## Considered Options

- Small enhancements in the small lane: rejected, because every enhancement needs careful consideration in a grill.

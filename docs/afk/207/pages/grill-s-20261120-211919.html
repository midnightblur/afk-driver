The ticket text

Goal

Port the v1 /afk:prototype skill (skills/afk/prototype/) to afkv2 as /afkv2:prototype.

What v1 does

  • Optional design-layer stage: after the PRD, before the SDD; only for features with net-new or changed UI (self-gates no_ui).
  • Anchors to the real frontend (design-system catalog → running app screenshots → frontend source).
  • Writes one self-contained, drivable HTML mockup (inline JS, fixtures, app shell + neighbor stubs); 2-3 divergent variants when direction is unclear.
  • Iterates on human feedback, then gates on a capability walk (every user story / AC clickable or logged as a gap) and a fidelity pass vs the live app.
  • Writes prototype/<screen>.html + PROTOTYPE.md; optional claude.ai/design share push.

New requirement

  • Lavish is optional: the developer can comment directly on the mockup UI (element annotations) instead of only via chat. Chat-only must still work.

  • afkv2 has no design-system skill: what replaces the catalog anchor?

  • Earlier decision (2026-10-09) to add a logic/state-model branch from mattpocock/skills LOGIC.md: in or out of this port?

# UI decisions are cited in the existing design sections

> Layer: Requirements
> Context ticket: 207

The afkv2 design document has fixed, gated headings and no UI section. `propose-solution` reads `PROTOTYPE.md` and cites each screen decision in the section where it changes the design, and designs each data or behaviour a decision names after `Implies:` in the section that owns it. The design format and its gate do not change; the mockup stays the UI record.

## Considered Options

- A new UI section in the design document. Rejected by the developer in card i-sdd, because it changes the template and its gate.
- The design only links to `PROTOTYPE.md`. Rejected by the developer in card i-sdd, because the design must show where a screen choice changes it.

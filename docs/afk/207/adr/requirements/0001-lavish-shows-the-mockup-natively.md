# Lavish shows the mockup natively

> Layer: Requirements
> Context ticket: 207

The prototype shows the mockup HTML file itself in lavish, apart from the afkv2 grill page engine: no page document, cards or rounds. Notes come back pinned to elements. The developer asked for it because driving a mockup is a different use case from grilling. Lavish is the default when its host runs, and chat is the fallback.

## Considered Options

- Show the mockup through the grill page engine. Rejected by the developer in round 0, because it is a different use case.
- Lavish off by default, turned on per run. Rejected by the developer in card i-optional, who accepted lavish on by default.

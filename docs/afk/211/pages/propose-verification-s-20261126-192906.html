The questions of round 1

Round 1 How 2 boundaries count: the install record and the milestone note Debate open

Section: 7 boundaries; 1 has a contract test today

A contract row proves that 2 sides agree on their messages. The 2 proposers disagree on whether this plan has 2 contract rows: the setup record (VR-062) and the note format (VR-042). Which reading?

A. Both are contract rows, and both boundaries count as having contract tests (the Claude proposer). Cost: VR-042 checks a text against its parser, which is closer to a lockstep check than to 2 parts agreeing.

B. Neither is a contract row: VR-042 is static, VR-062 is integration, and both boundaries get a proposed ticket (the Codex proposer). Cost: the record readers already have tests that can take the new line; a ticket for that defers 1 small test.

C. Split them: VR-062 is a contract row, because setup's real writer writes the record and each real reader reads it; VR-042 is static, and the note boundary gets a ticket to replay recorded notes through the parser (my reconcile).

Recommended: C

Each row gets the level that matches what it runs: 2 real programs agree on the record, but the note has only 1 program and a text.

# A clear note settles a point

> Status: Accepted
> Audited: 2026-10-29
> Layer: Requirements
> Context ticket: GitHub #153

A point on a grill or design page settles by an explicit mark, or by a note that the agent reads as clear and not ambiguous. The agent states its reading of each such note in its reply. The point gets a "settled by note" state, which differs from "settled by mark", so an audit can tell the two apart. A point with conflicting signals stays open. Why: the owner found marks-only too rigid (GRILL-LOG V-5, T-22). This reverses the round-1 steer "free notes never stand in for an accept".

## Consequences

- One click reopens a note-settled point.
- A note on a settled item reopens it. A note on a map node is a steer for that node.

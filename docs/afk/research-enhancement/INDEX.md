# research-enhancement — start here

Adds four opt-in capabilities to the afk plugin: a research skill that answers world questions from cited primary sources and surfaces the team's own settled priorities as advisory findings; a prepared-ask bar so anything reaching a human carries a recommendation, evidence and the cost of waiting; a consultation skill where a second provider investigates independently and challenges once, with dissent kept; and a subscription-only dispatcher that runs those providers headless and resumes unfinished read-only work on another host. Absent config keeps today's behaviour. Pilot providers are Claude Code and Codex CLI.

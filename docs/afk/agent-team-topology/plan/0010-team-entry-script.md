## Goal
Build the team entry script: the one top-level script agents call, scripts/afk-team.py, with its logic in scripts/team/entry.py and the label and name rule in scripts/team/naming.py (file names: plan decision D-3). It dispatches the six transport verbs, one JSON object each, and owns every check the design gives it: edges and kinds on agent-send, the start-request check, the four-part label and agent name, the manifest writes around agent-start's transport call with its exit 4 and exit 5 paths, the job supervisor start, finished delivery to the report target, the settings copy, and the charter work (one charter file per role at resolve time, the launch prompt that names it before the brief, and the launch-only value naming it). The slice ends at the script: the transport kinds, the resolver, the manifest module, the supervisor's own loop, cleanup and the team skill's run procedure are other subtasks.

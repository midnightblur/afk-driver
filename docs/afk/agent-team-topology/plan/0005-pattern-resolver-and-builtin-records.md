## Goal
Build the pattern resolver scripts/team/resolver.py and ship the five built-in pattern records BP-1 to BP-5 as versioned data files under scripts/team/patterns/, with the charters of BP-2 to BP-5 and the pattern standard's one home scripts/team/patterns/STANDARD.md (file names: plan decision D-3). The resolver reads built-in and saved records and a one-off pattern in the field shape of a record, follows includes, flattens the team before any start, fills roles, adds a moderator, applies talk edges and report targets, and refuses with exit code 2 on every case the design names, including a missing or empty charter part. The same change adds BP-1 to BP-5 to the genericity allow list, a FRESHNESS.md row and a CHANGELOG line. The slice ends at the resolved pattern: writing charter files, launching agents and refusing messages at send time are other subtasks.

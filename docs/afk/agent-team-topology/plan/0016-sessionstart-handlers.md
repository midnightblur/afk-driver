## Goal
Add the charter pointer, the only new SessionStart handler: hooks/charter-pointer.sh (file name: plan decision D-3), appended after worktree-prune.sh at index 6 of the `*` group of both hooks files, so the group ends with 7 handlers. It prints one line pointing a pane agent (an agent in its own terminal pane) back at its charter file, only after a compaction and only when the launch-only value AFK_CHARTER_FILE is set. The slice covers the handler, its registration, its setup trust position and E-table row, and its smoke and probe proofs. The pane-agent rule's short form is not a SessionStart handler: it is one BEHAVIORS.md entry, another subtask (plan D-19). The value agent-start sets is another subtask.

# scope-and-impact — stayed in lane, blast radius known

Default `class: scope` (a genuinely broken direct caller is `correctness`).

Confirm every changed path matches a `## Scope` glob (out-of-scope file = finding), no forbidden pattern (liquibase/UpgradeGroup), no unrelated churn (stray `package-lock.json` reflow, formatter-only diffs in untouched files). Then assess blast radius: for each changed public symbol (method/class signature, REST path, DTO field, event), enumerate its callers with the seed map — `python "$AFK_PLUGIN_ROOT/skills/utils/investigate/scripts/seed_map.py" --repo . --subject <symbol> --type Q2 --config auto --out <review scratch>/callers-<symbol>.json` — and read its B1/B2/B4 hit sets as the caller set (it writes only to the review's scratch directory; the reviewer still edits nothing). A B-row that comes back `partial` or `unverified` is itself a finding — the caller set is not known — graded on this checklist's scale and surface as a finding any caller whose contract the diff changed but did **not** update or cover with a test. A changed `*-client` DTO or endpoint signature with downstream consumers in other services is high severity.

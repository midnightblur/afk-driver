# PRD — orders list

## Problem Statement

A buyer cannot see the orders.

## User Stories

1. As a buyer, I want to see my orders, so that I know what I bought.
2. As a buyer, I want to filter my orders by status, so that I find an open order.

## Acceptance Criteria

- [ ] AC-001 The orders screen → lists each order with its total.
- [ ] AC-002 A status filter → shows only the orders of that status.

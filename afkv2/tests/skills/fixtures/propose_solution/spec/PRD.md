# PRD — order export

## Problem Statement

A clerk copies each order into a spreadsheet by hand, and each copy takes 5 minutes.

## Solution

The clerk exports the orders of one day into one file.

## User Stories

- As a clerk, I export the orders of one day, so that I stop copying by hand.

## Acceptance Criteria

- [ ] AC-001 The export writes one row per order.

## Worked examples

### WE-01 One day with 2 orders

2 orders give 2 rows.

## Access & validation policy

Clerks may export. Guests may not.

## Implementation Decisions

None.

## Testing Decisions

One test per criterion.

## Out of Scope

Scheduled exports.

## afkv2

This folder is a separate plugin, AFK 2.0 beta: its skills run as `/afkv2:<skill>`, its spec and module map are in `docs/afk/afkv2/` at the repository root (`SDD.md` §8), its words come from `GLOSSARY.md` here, and a beta installs from a git tag `afkv2-<version>`, never a tag that starts with `v`, which starts the v1 release workflow. To extend it, add a page component as one file in `engine/components/` that calls `register_component`, add a page format as a new `engine/schema/page-v<N>.schema.json` because the engine must still open every older format, keep tracker and forge calls behind `ports/`, and after an edit to `core/CORE-BEHAVIORS.md` run `scripts/plugin_check.py build` to regenerate `hooks/built/`. Every change must pass `scripts/plugin_check.py check`, which applies the no-v1-name rule of `SDD.md` §8, and v1 stays frozen: record a v1 defect in the `SDD.md` §7 table "v1 defects afkv2 must not repeat", not as a v1 change.

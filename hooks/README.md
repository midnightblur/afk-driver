# Harness gates

Deterministic quality gates shipped with the afk plugin. Stop gates and the PreToolUse hooks (`lavish-dark.sh` plus the adopted harness guards below) are wired in `hooks/hooks.json`; `app-start-gate.sh` is on-demand. All gates run against the repo the session works in (`git rev-parse --show-toplevel`); the Maven/format gates no-op outside a core-services-shaped checkout (no `all-modules-pom.xml` at root ⇒ silent allow).

**Adopted harness gates.** Four gates are registered here but live in
`tools/payable/ai-agents/harness/hooks/` (their one home, shared with the
`code-quality/` assets they read and the generated Codex layer that invokes the
same scripts): `crowdstrike-guard.sh` + `explore-counter.sh` (PreToolUse) and
`java-rules-gate.sh` + `i18n-parity-gate.sh` (Stop). `hooks.json` invokes them
via `${CLAUDE_PROJECT_DIR}` (existence-guarded, so the plugin stays inert in a
repo without them) rather than `${CLAUDE_PLUGIN_ROOT}` — directory-source
plugins are snapshotted at install, and these gates must track the checkout,
not the snapshot. Their escape hatch is the harness one: `.claude/.gate-disabled`
(no `hooks/` segment). The standalone `payable-harness` plugin that used to
carry them is retired (its `.claude-plugin/` manifests and `hooks/hooks.json`
are deleted) — this plugin is the single registration surface; anyone still
carrying an old `payable-harness` install should uninstall it.

| Gate | Trigger | Blocks when | Typical cost |
|---|---|---|---|
| `wiring-gate.sh` | Stop hook, any NEW file (worktree + commits not yet in `origin/master`) | new artifact has zero referrers and no IOU in `.claude/wiring-ious.md`; with `WIRING_FINAL=1`, open IOUs also block | ~1–5s |
| `skill-registry-gate.sh` | Stop hook, this plugin's checkout present | a plugin registry drifted from disk — (A) a `skills/afk/*/SKILL.md`, `skills/utils/*/SKILL.md`, or `agents/*.md` isn't listed in `.claude-plugin/plugin.json`'s `skills`/`agents` array (invisible to the plugin loader), or an array entry points at a dir that no longer exists; (B) a skill name has no `/afk:<name>` / `` `<name>` `` / path mention in the plugin's `CLAUDE.md` + `README.md` (uncatalogued = invisible to an agent reading the harness); (C) an env var read by `hooks/*.sh` but assigned nowhere in `hooks/` is absent from the setup register's E-table (`skills/afk/setup/MANIFEST.md`) | <1s |
| `codex-drift-gate.sh` | Stop hook, changed file under a canonical source (plugin skills/agents/hooks/manifests, project `.claude/skills`) or a generated tree (`.agents/`, `.codex/`, `codex-sync/`) | `codex-sync/generate.py --check` reports a generated Codex artifact missing/differing/stale — regenerate and commit alongside the change | <1s scope no-op; ~2s check |
| `genericity-gate.sh` | Stop hook, changed/untracked plugin `*.md` | an added line references a concrete ticket ID or a product source file/class (11700-payable, verification/ harness excluded) not listed in `genericity-allow.txt` — plugin prose must state the mechanism/pattern class, never the incident instance that motivated it | <1s |
| `maven-compile-gate.sh` | Stop hook, changed `.java` | any changed submodule fails `compile` (reactor, `--also-make`) | 30s–3min |
| `ui-lint-gate.sh` | Stop hook, changed `.js/.ts/.vue` | ESLint errors in changed files (nearest `.eslintrc.*` workspace) | ~10s |
| `java-format-gate.sh` | Stop hook, changed `.java` | changed file not conformant to the repo-root `eclipse-code-formatter.xml` (STRICT: touched legacy file ⇒ reformat whole file via the Fix command it prints) | ~5s/module |
| `…harness/hooks/java-rules-gate.sh` | Stop hook, changed `.java` | error-tier CSJ rule violation (standalone Checkstyle over changed files; rule table + severities: `tools/payable/ai-agents/harness/code-quality/RULES.md`; warning-tier findings print, never block; suppress a genuine exception with `// CSOK: <id> <reason>`) | ~5–15s |
| `…harness/hooks/i18n-parity-gate.sh` | Stop hook, changed `**/i18n/<locale>/*.json` | a caption key **added** by this change to one locale is missing from a sibling locale (legacy drift ignored; checker: `harness/code-quality/i18n-parity.mjs`) | <5s |
| `…harness/hooks/crowdstrike-guard.sh` | PreToolUse on Bash/PowerShell/Glob/Grep/lean-ctx | denies recursive walks of Windows system roots that trip CrowdStrike Falcon sensor-tamper alerts (rule: `harness/hooks/windows-safety.md`; debug bypass `CROWDSTRIKE_GUARD_OFF=1`) | <1s |
| `…harness/hooks/explore-counter.sh` | PreToolUse on search-shaped tools (Grep/lean-ctx/IntelliJ search) | never blocks — tallies exploration calls per session and nudges delegation to an Explore agent at thresholds 3/6/10 | <1s |
| `lavish-dark.sh` | PreToolUse hook on Bash/PowerShell, command is a `lavish-axi <file>` render | never blocks — forces dark mode on the artifact HTML before render (lavish-axi has no theme param): DaisyUI artifact ⇒ `data-theme="dark"` on `<html>`; otherwise ⇒ luminance-gated invert override; idempotent via marker comment; non-render subcommands and non-HTML args no-op | <1s (non-lavish commands: ~0s) |
| `app-start-gate.sh` | on demand (NOT a Stop hook) | service fails to boot: `package --also-make` + `java -jar`, watches for `Started *Application` | 3–6min (`APP_START_REUSE=1` hit: ~0s) |
| `mutation-probe.sh` | on demand (NOT a Stop hook) | never blocks — prints PIT mutation results (`ok` with survived/no-coverage mutants, or `unavailable`) for the review gate's test-strength signal | 2–15min |
| `lesson-append.sh` / `lesson-digest.sh` | on demand (NOT Stop hooks) | never block — sole emitting/parsing sites of the workflow lesson ledger (main-checkout `.claude/lessons/LEDGER.jsonl`; grammar: `skills/afk/lessons/LEDGER-FORMAT.md`); appends are best-effort like metrics emission | <1s |
| `branch-name-gate.sh` | **git** `reference-transaction` hook (NOT an agent-harness hook); auto-installed on `SessionStart`; **enforces only under an agent** (agent-runtime env marker set — see rule below) | an **agent** **creating** a new local branch whose name doesn't match `kapteyn/development/<username>/<slug>` — human-driven creation, and checkouts/updates of existing or remote-tracking branches, are never gated | <10ms |

Rules:

- **`branch-name-gate.sh` is a git hook, not an agent-harness hook** — not wired into `hooks.json`; it runs inside git itself on ref updates, which is what catches *every* creation path an agent uses, no shell-command parsing. Enforcement scope (agent-only markers, creation-only, remote-DWIM allowance) and escape hatches (`AFK_SKIP_BRANCH_CHECK=1`, `git config afk.branchNameGate false`, removal): script header. Installation (`SessionStart` runs `install-git-hooks.sh --quiet`, so enabling the plugin is the whole opt-in; idempotent / self-scoping / worktree-safe / non-destructive; fallbacks: `/afk:setup` register H5 or a manual run): `install-git-hooks.sh` header.
- **Caveat — agent-launched IDE/terminal.** The marker propagates to child processes, so if an agent launches IntelliJ or a shell (e.g. `create-worktree --open`), branch creation *within that launched process* inherits the agent marker and is still gated. A terminal/IDE you started yourself is unaffected. Use the bypass or config-disable in the rare launched-process case.

- Escape hatch for all Stop gates: create `.claude/hooks/.gate-disabled` **in the repo being gated** (leave a reason inside; delete to re-enable).
- **Provider shim.** `hooks/lib/provider.sh` is the one home for provider-specific surface (Claude Code vs OpenAI Codex CLI) — detection, paths, envelope parsing, decision emission, block contract, the synced harness copy: its header. Hooks touching any of that source it; gate logic stays provider-free. Smoke tests: `bash tools/payable/ai-agents/codex-sync/tests/hook-smoke.sh` (every envelope-consuming hook under both provider modes).
- **Pass cache.** The Stop gates remember their last **pass** as a content hash under `.claude/hooks/.gate-cache/` in the gated repo (`gate-cache.sh` header: gate list, key, contract; hits emit no metrics line, failures store nothing). The wiring gate bypasses the cache in final mode (`WIRING_FINAL=1`) — a normal-mode pass with open IOUs must not satisfy the final-mode run that blocks on them. `GATE_CACHE_DISABLE=1` forces every run to do real work.
- Wiring gate: verdict model, IOU ledger grammar (`.claude/wiring-ious.md`), and the `/verify-seams` judgment boundary: script header; skip heuristics (framework-wired annotations, convention-consumed filenames, token rules) commented at each check in the body.
- Maven-invoking gates serialize via `maven-lock.sh` — rationale, lock path/staleness, and the `acquire_maven_lock`/`release_maven_lock` wrap contract for any new gate's mvnw call: its header.
- Maven invocations are reactor-based with `--also-make` — never trust `~/.m2` for sibling modules; stale jars cause APT `Expected a DeclaredType, got <error>` false failures. Cross-**worktree** local-repo races are designed out one level up: worktrees provisioned by `skills/afk/bug/scripts/create-worktree` carry a private `.mvn/maven.config` (`-Dmaven.repo.local=<worktree>/.m2/repository`, seeded minus `*-SNAPSHOT`), which every `./mvnw` a gate runs inherits automatically — the maven-lock above still serializes reactors *within* one checkout.
- `lesson-append.sh` / `lesson-digest.sh`: usage, always-exit-0 best-effort contract, `LESSON_LEDGER_DISABLE=1` / `LESSON_LEDGER_FILE`: script headers; grammar: `skills/afk/lessons/LEDGER-FORMAT.md`.
- `mutation-probe.sh`: exit 0 = mutation signal printed; exit 3 = `unavailable`/timeout — callers treat it as "no signal", never a failure. Usage, `PITEST_VERSION` / `MUTATION_TIMEOUT`, the per-service `pitest-junit5-plugin` enablement snippet: script header. The review gate's test-veracity skill owns the sampling rule.
- `app-start-gate.sh [leaf-module]` (default `11700-payable/payable`), run from the repo root: `bash tools/payable/ai-agents/plugins/workflow/hooks/app-start-gate.sh`. Exit codes: 0 started, 2 code failure (incl. a UI build failure or a build leaving no `public/index.html`), 3 environment failure (not a code bug), 4 timeout. Env vars — semantics in the script header: `APP_START_TIMEOUT`, `APP_START_PORT`, `APP_START_KEEP`, `APP_START_SKIP_UI` (why it is NOT Maven `-DskipUi=false`: the "UI pass" comment in the script body), `CI_PROJECT_DIR`, `APP_START_REUSE`. Kept fixed-port instance state + self-cleanup: header.
- Java format fix: the gate prints the exact `formatter-maven-plugin:format` command scoped to the failing files. Formatter config is the repo-root `eclipse-code-formatter.xml`.
- **Latency metrics & budget.** Every gate run doing real work (scope-check no-ops excluded) appends one JSONL line to `.claude/metrics/gate-latency.jsonl` **in the gated repo** via `gate-metrics.sh` (sourced by all nine emitting scripts — the seven Stop gates plus `app-start-gate.sh` and `mutation-probe.sh`): `ts`, `gate`, `result` (`pass`/`blocked`, or `ok`/`code_failure`/`env_failure`/`timeout` for app-start), `duration_ms`, plus gate-specific fields (`lock_wait_ms` = maven-lock serialization tax, `package_ms`, `detail`). Summarize with `bash tools/payable/ai-agents/plugins/workflow/hooks/gate-metrics-report.sh` (per gate: runs, red count, p50/p95/max). Budget: p95 should stay within the **Typical cost** column above — a sustained breach triggers optimization (compile gate: check `lock_wait_ms` share first, then evaluate `mvnd`/offline `-o`; app-start: check `package_ms` vs boot time, `APP_START_SKIP_UI`), never optimize a gate without this data. `GATE_METRICS_DISABLE=1` silences emission; emission failures never fail a gate.
- `skill-registry-gate.sh`: the three checks (incl. the env-toggle E-table), ambient-var whitelist, and the mechanical-vs-`/afk:setup audit` boundary: script header. Add a skill dir → same commit adds it to `plugin.json`'s `skills` array **and** a `/afk:<name>` mention to the plugin's `CLAUDE.md` + `README.md`, or this gate blocks the next Stop.
- UI lint: nearest-ancestor `.eslintrc.*` = lint workspace, silent-allow rules: script header; the `eslint` binary resolves from the hoisted root `node_modules` via `npx --no-install`.
